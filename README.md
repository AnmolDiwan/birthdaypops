# 🎂 Happy Birthday Pap! — Vintage Bollywood Edition

A beautiful vintage Bollywood-themed birthday website for Pap.

## 🎵 Adding Songs

1. Place your MP3 files in the `songs/` folder
2. Name them: `song1.mp3`, `song2.mp3`, ... `song10.mp3`
3. To change song names, edit the `playlist` array in `app.js` (line ~91)

## 🖼️ Adding Photos

### Album Art (for the record player)
- Place images in `images/` folder
- Name them: `album1.jpg`, `album2.jpg`, ... `album10.jpg`

### Family Photos (for message cards)
- `images/family1.jpg` — Your photo
- `images/family2.jpg` — Mom's photo
- `images/family3.jpg` — Sister's photo

### Memory Photos (for gallery)
- `images/memory1.jpg` through `images/memory6.jpg`

## ✏️ Customizing Messages

Edit the message text in `index.html`:
- **Your message**: Find "Son / Daughter" section (~line 128)
- **Mom's message**: Find "Wife" section (~line 142)
- **Sister's message**: Find "Daughter" section (~line 158)

## 🚀 How to Open

Simply open `index.html` in any modern browser — no server needed!

Or use a local server for best results:
```bash
npx serve .
```
